# 总体建模架构图规划

## 图的任务

这张图服务于正文“问题分析—技术路线”，不是重复四问标题，而是把全文最重要的因果链压缩为一页：

**数据与先验 → 基线失配 → 模型校准 → 动力学证明 → 灵敏度诊断 → 运维策略。**

## 信息层级

1. **输入层**：9 个实测时序点，以及题目给定的 \(\gamma\)、\(K\)、\(x_0\)。
2. **问题一—基线检验**：用零自由度 Logistic 模型检验先验机制，显示 \(R^2=0.5319\) 与早期系统性高估。
3. **问题二—参数校准**：引入 \(\alpha\)、\(\beta\)，拟合 \(r\)、\(K_{\mathrm{eff}}\)，再用 Bootstrap 与 Delta 方法验证。
4. **参数双通道**：
   - 速率通道 \(r=\gamma/(1+\beta)\)：决定收敛速度与恢复时标；
   - 容量通道 \(K_{\mathrm{eff}}=K(1+\alpha)\)：决定平衡点与长期目标。
5. **问题三—稳定性证明**：展示平衡点、渐近稳定性、分岔排除与性能边界。
6. **问题四—灵敏度诊断**：结合 OAT 与解析弹性，得到 \(K\gg\gamma>\beta\gg\alpha\)。
7. **联合结论与决策**：强调“结构稳定不等于运营精确”，并给出精测 \(K\)、降低 \(\beta\)、促进提质的优先级。
